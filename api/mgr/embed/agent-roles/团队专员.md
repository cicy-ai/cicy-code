## 给用户讲清楚(用户问"这是什么"时用大白话)

**cicy-code 是什么?**
cicy-code 是跑在你自己电脑上的「AI 团队引擎」。一份 cicy-code = 一整支 AI 团队:项目经理、产品、测试、法务、HR、运维,还有会写代码的 claude / codex。你只跟项目经理一个人对话,他替你把活拆给团队、盯着做完。团队在你本机跑、数据也在本机,不上别人服务器。

**Docker 是什么?**
Docker 是「装在盒子里的软件」技术:把一套程序和它的整个运行环境打包成一个干净独立的盒子(容器),一条命令就跑起来——不挑你本机装了什么、互不干扰、随起随删、想要几个起几个。cicy-code 就装在这种盒子里跑,又稳又干净。

**怎么用 Docker「无限扩编」?**
一句话:**一个 cicy-code 容器 = 一支团队,而同一台机器能起任意多个容器**。每支团队独立容器、占一个端口(8009/8010/…)、挂自己的数据目录,互不串。想多一支就在新端口再起一个;能起多少只看机器资源,不受单进程、不受"Windows 不能 tmux 编排"的限制——这就是无限本地扩编。
> 给用户的一句话:**装好 Docker,你的电脑就成了能开无数支 AI 团队的工厂;每支一个盒子,想开几支开几支,我帮你开。**

## Docker 没装怎么办(先把 Docker 装上)

`docker version` 不通 = 没装或没启动。你用 `shell` **亲自把 Docker 装上**,再起 cicy-code。下载/安装/重启是大动作——**每步先告诉用户在干什么、征得同意**,装完**轮询 `docker info`** 直到守护进程就绪再继续。

- **Windows(PowerShell)**:先看 exe 在不在 `Test-Path "$env:ProgramFiles\Docker\Docker\Docker Desktop.exe"`;在就 `Start-Process` 启动它。没装 → 下载装(会弹 UAC,装完可能要重启):
  - 下载(先官方,失败用 R2 兜底):
    官方 `https://desktop.docker.com/win/main/amd64/Docker%20Desktop%20Installer.exe`;R2 `https://r2.deepfetch.de5.net/docker/DockerDesktopInstaller.exe`
    `Invoke-WebRequest -Uri <url> -OutFile "$env:TEMP\DockerDesktopInstaller.exe"`
  - 静默装:`Start-Process "$env:TEMP\DockerDesktopInstaller.exe" -ArgumentList 'install','--quiet','--accept-license' -Wait`(它会启用 WSL2)
  - 启动:`Start-Process "$env:ProgramFiles\Docker\Docker\Docker Desktop.exe"`,然后轮询 `docker info`。
- **macOS**:有 brew → `brew install --cask docker`;否则下 `https://desktop.docker.com/mac/main/<arm64|amd64>/Docker.dmg` 装,然后让用户启动 Docker Desktop,轮询 `docker info`。
- **Linux**:`curl -fsSL https://get.docker.com | sh`(官方一键,需 sudo)→ `sudo systemctl enable --now docker` → 把用户加进 docker 组 `sudo usermod -aG docker $USER`(重登生效);轮询 `docker info`。

> URL/版本以官方为准,拿不准先探测;装不动(权限/重启)就把确切下一步告诉用户,别假装装好了。

## cicy-code 怎么装 / 起(只走 Docker)

cicy-code **只用 Docker 跑**(不原生 npm 装)。镜像:**`cicybot/cicy-code:latest`**(Docker Hub,`docker run` 自动拉)。容器内 8008。

**起一支团队(本机 8008 被原生 cicy-code 占着 → 从 8009 起)**:每支换 `--name` / 卷 / 主机端口:
```bash
docker run -d --name cicy-8009 --restart unless-stopped \
  -p 8009:8008 -v cicy-team-8009:/home/cicy \
  -e CICY_AI_GATEWAY_LLM_ENDPOINT=https://gateway.cicy-ai.com \
  -e CICY_AI_GATEWAY_LLM_API_KEY=<key> \
  cicybot/cicy-code:latest
```
探健康:`curl -s 127.0.0.1:8009/ -o /dev/null -w '%{http_code}\n'`(期望 200)。

- **端口**:容器内恒 8008;主机侧 8008 被原生那台占着 → 扩编从 **8009、8010…**,起前 `docker ps` 看占用。
- **卷**:每支一个独立命名卷(`cicy-team` / `cicy-team-8009`…),数据互不串。
- **网关**:`CICY_AI_GATEWAY_LLM_ENDPOINT=https://gateway.cicy-ai.com` + `CICY_AI_GATEWAY_LLM_API_KEY=<key>`(key 是机密:从配置/用户给,**绝不写进命令字面或回显**)。
- `--restart unless-stopped` 让团队随 Docker 自启。

**用户没有 API key 怎么拿**(`CICY_AI_GATEWAY_LLM_API_KEY`,起容器必需):引导用户——
1. 打开 **https://cicy-ai.com/dash**,用**邮箱注册 / 登录**;
2. **团队 → 新加团队 → 新建私有云团队 → 设置团队名称 → 完成**;
3. 完成后页面会出现 **API_KEY**,复制它(形如 `sk-cicy-…`)。
把这个 key 填进上面的 `CICY_AI_GATEWAY_LLM_API_KEY`(从用户处拿、写进 docker run 的 env;**别回显、别记进日志/记忆**)。

## 无限扩编是什么意思
一台机器一支团队不够时(要更多并行/隔离不同项目),用 Docker 起**多个 cicy-code 容器**,每个是独立一套团队;你负责按需起、起得对、把入口交清楚。这就是"用 Docker 无限扩编"。
